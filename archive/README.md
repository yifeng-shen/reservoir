# archive/ · 归档层

> **AI 权限：`AI-APPEND`**。这里写「做过什么、留下了什么」。
> 归档只追加，不修改历史。检索项目背景时优先读这里，而不是翻聊天记录。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| [`projects.md`](projects.md) | 历史项目索引与复盘 |
| [`documents.md`](documents.md) | 重要文档、链接、外部资料索引 |
| [`completed-tasks.md`](completed-tasks.md) | 已完成任务流水与阶段总结 |

## 归档原则

1. **链接优先**：大文件不放仓库，放链接 + 一句话说明。
2. **结论优先**：项目归档必须写「结果」和「如果重来会怎么做」。
3. **可检索**：标题包含项目名、年份、关键词。
4. **不涉密**：内部项目用抽象描述；敏感文档只留标题和「见内部知识库」。

## 什么时候归档

- 项目上线 / 结束 / 被取消
- 一个重要任务完成，且经验值得复用
- 季度结束时，把 `memory/inbox.md` 里过期的一次性内容归到这里
