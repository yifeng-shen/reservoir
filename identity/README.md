# identity/ · 身份事实层

> **AI 权限：`AI-READONLY`**。这里写「我是谁」，是整套记忆系统的地基。
> AI 只能引用，不能改写。发现信息过期时，让它写入 `memory/inbox.md` 提议，由你确认后手工修改。

## 文件说明

| 文件 | 内容 | 更新频率 |
| --- | --- | --- |
| [`profile.md`](profile.md) | 基础身份：称呼、城市、时区、职业、一句话介绍、核心标签 | 半年 |
| [`career.md`](career.md) | 职业经历、能力结构、行业方向、当前工作 | 季度 |
| [`tags.md`](tags.md) | 核心标签、关键词、AI 检索提示、反标签 | 季度 |
| [`goals.md`](goals.md) | 人生方向、3 年 / 1 年 / 季度目标、非目标 | 季度 |

## 怎么填

1. 先填 `profile.md`，10 分钟即可，其他文件可以留空。
2. 占位符统一写成 `{{...}}`，填完一个删一个；`python3 scripts/validate.py --strict` 会列出剩余占位符。
3. 事实要短、可验证、少形容词。例如「后端工程师，做支付系统」优于「资深技术专家」。
4. 不要写手机号、住址、身份证、公司内部代号、未公开的财务信息。

## 为什么 AI 不能写

身份事实一旦被模型「顺手补全」，就会以假为真地污染所有后续对话。
所以这里只允许人类编辑；AI 的观察一律进 `memory/`，由你定期筛选。
