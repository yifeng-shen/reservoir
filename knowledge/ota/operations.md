# AI-EDIT: OTA 运营 SOP

> 项目实际执行情况写私密层 `projects/<项目>/operations.md`。

## 日常（每天）

- [ ] 检查新增订单与异常订单（{{超时未确认 / 到店无房}}）。
- [ ] 回复新评价，处理差评。
- [ ] 检查价格与库存，处理关房/满房。
- [ ] 查看曝光、点击、转化，记录异常波动。
- [ ] 处理平台消息与活动报名。

## 每周

- [ ] 对比同商圈价格带。
- [ ] 复盘本周转化漏斗，找 1 个可优化点。
- [ ] 检查评价分与评价数变化。
- [ ] 更新活动排期。
- [ ] 输出一页周报：{{曝光 / 点击 / 转化 / 入住率 / 客单价}}。

## 每月

- [ ] 平台规则复核：佣金、活动、违规。
- [ ] 竞品与价格带复盘。
- [ ] 评分与口碑复盘。
- [ ] 下月活动与库存计划。
- [ ] 把可复用结论写入本文件或 `memory/experiences.md`。
