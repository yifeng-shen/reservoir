# AI-APPEND: 重要决策记录

> **给 AI 的指令**：需要历史决策背景时读这里；不要重复推荐已经被否决的方案。
> 只追加，不修改历史决策。新决策先写 `inbox.md`，转正后追加到这里。

## 什么算「重要决策」

满足任一条件：

- 影响超过 1 个月
- 涉及金钱、职业、健康、重要关系
- 推翻了以前的决定
- 当时很纠结，未来可能重演

## 决策条目模板

```markdown
### YYYY-MM-DD · 决策标题
- **背景**：为什么需要做这个决定
- **选项**：A / B / C，各自的代价
- **决定**：选了什么
- **理由**：最关键的一条理由
- **预期结果**：希望发生什么
- **复盘**：待观察 / 结果如何
- **来源**：人工 / ChatGPT / Claude …
```

### 2026-10-31 · 建立 Reservoir 个人记忆系统
- **背景**：多个 AI 平台各自记忆，换设备/换模型就要重新解释自己
- **选项**：A. 每个平台单独维护；B. Notion 数据库；C. GitHub 公开 Markdown 仓库
- **决定**：C，GitHub 仓库 + 只读身份层 + 追加式记忆层
- **理由**：纯文本、可版本化、任何 AI 都能通过 URL/API 读取，无平台锁定
- **预期结果**：新 AI 接入成本降到一句话；记忆可回滚、可审计
- **复盘**：待观察（建议 1 个月后回看）
- **来源**：人工
