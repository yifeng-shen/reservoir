## 优先写什么

1. 我明确表达过的偏好（「以后都这样」）。
2. 我纠正过你的地方（「不对，应该……」）。
3. 反复出现的任务模式（每周都要做的报表）。
4. 我做过的重要取舍及其理由。

## 不要写什么

- 一次性的临时要求。
- 你的猜测（除非标「置信度：低」并且说明依据）。
- 已经存在于 `preferences.md` / `decisions.md` 的重复内容（先搜索）。
