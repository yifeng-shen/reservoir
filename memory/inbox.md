> 只追加，不修改、不删除已有条目。每条必须带来源与置信度。

## 优先写什么

1. 我明确表达过的偏好（「以后都这样」）。
2. 我纠正过你的地方（「不对，应该……」）。
3. 反复出现的任务模式（每周都要做的报表）。
4. 我做过的重要取舍及其理由。

## 不要写什么

- 一次性的临时要求。
- 你的猜测（除非标「置信度：低」并且说明依据）。
- 已经存在于 `preferences.md` / `decisions.md` 的重复内容（先搜索）。

### 2026-10-31 · 初始化
- **场景**：搭建 Reservoir 记忆系统
- **结论**：记忆写入采用「inbox → 人工转正」两段式，AI 不直接改写正式记忆
- **原因**：避免单次对话的偶然偏好污染长期画像
- **边界**：紧急且明确的偏好（如「以后都用中文」）可直接追加到 `preferences.md`
- **来源**：人工
- **置信度**：高
