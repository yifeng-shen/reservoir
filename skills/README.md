# skills/ · 技能层

> **AI 权限：`AI-EDIT`**。这里写「我会什么、在学什么、下一步补什么」。
> 用于判断任务能否交给我、推荐学习路径、避免把「了解」当「精通」。

## 文件说明

| 文件 | 内容 | 更新频率 |
| --- | --- | --- |
| [`mastered.md`](mastered.md) | 已掌握技能矩阵（含等级与证据） | 季度 |
| [`learning-plan.md`](learning-plan.md) | 当前学习计划、资源、里程碑 | 每月 |
| [`backlog.md`](backlog.md) | 待提升能力清单（按优先级） | 季度 |

## 等级定义

| 等级 | 含义 | 判断标准 |
| --- | --- | --- |
| L1 了解 | 知道概念 | 能读懂、能提问 |
| L2 会用 | 能完成简单任务 | 在模板/指导下能交付 |
| L3 熟练 | 能独立交付 | 不需要指导，能处理常见异常 |
| L4 精通 | 能设计系统 | 能做技术选型、带人、处理边界情况 |
| L5 专家 | 能定义标准 | 行业内有可验证的影响力 |

> 填写时宁可低报，不要高报。AI 会按等级决定给你多少上下文。

## 与记忆系统的关系

- 技能**事实**（会什么）在这里维护。
- 学习过程中的**经验教训**写入 `memory/experiences.md`。
- 完成的课程/项目归档到 `archive/completed-tasks.md`。
